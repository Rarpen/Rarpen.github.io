# Panel

Painel escuro com contorno teal aceso: fundo `surface`, borda 2px `border-glow`, `radius-lg` e brilho difuso `shadow-glow-soft`. É a assinatura visual do tema escuro — usado no bloco de Contato, em destaques e como base do ProjectCard. O consumidor fornece o conteúdo. Não empilhe painéis dentro de painéis.
