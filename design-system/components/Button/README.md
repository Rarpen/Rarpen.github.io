# Button

Botão de ação em três variantes: `rp-btn-primary` (teal, ação principal de navegação como “Ver projetos”), `rp-btn-cta` (laranja, contato — no máximo um por tela) e `rp-btn-ghost` (secundário com borda). Texto sempre preto sobre teal/laranja (`on-accent`). Use `<a class="rp-btn …">` para links e `<button>` para ações. Seta opcional em `<span class="rp-arrow">→</span>`, que anda 3px no hover. `rp-btn-sm` para contextos compactos.
