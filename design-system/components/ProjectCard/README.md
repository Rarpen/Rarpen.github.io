# ProjectCard

Card de projeto para a grade da seção Projetos: título (`rp-card-title`), descrição de 2–3 linhas com foco no resultado (`rp-card-desc`), tags de tecnologia e link (`rp-link`). No hover sobe 4px, ganha `shadow-card` e borda teal. Grade: 1/2/3 colunas em 0/640/1024px, gap `space-6`. O consumidor fornece título, descrição, lista de tecnologias e URL (repositório, demo ou post do LinkedIn).
